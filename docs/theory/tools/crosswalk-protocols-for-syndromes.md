# Crosswalk — protocols for syndromes, read through the model

*The process-based critique of protocol-per-syndrome is a slide with seventy entries on it. This page takes a widely circulated version of that list and asks, one row at a time: which floor, which lever, and does the drawer already hold it — or is it out of scope, and why. The point is not that the model absorbs everything. The point is where it compresses, where it declines, and where it disagrees with the list.*

**Lever vocabulary** (from [[How the Major Modalities Recalibrate Priors]]): *content* · *prediction error* (furnace experiments) · *precision* (attention, defusion) · *reconsolidation* (activation + mismatch) · *furnace-interrupt* (block the move) · *script revision* · *the dimmer* (conditions, valve) · *name the substrate* · *calibration gate*.

**Status key:** **DRAWER** = a protocol or module in the drawer covers it · **LENS** = the model locates it; no protocol written · **GATE 2** = reversed dial — prior-loosening and prediction-error work are contraindicated; different standard of care · **MEDICAL GATE** = calibration gate first; body gets medicine before alarms are treated as false · **SUBSTRATE** = floor-8 / environment work, not an upper-floor tool · **PROGRAM** = not psychotherapy in the model's sense · **TEST** = the model makes a claim that differs from, or explains, the entry's evidence.

## What the table says, counted

Sixty-three entries. Roughly: **twenty-six** the drawer already covers directly or as a module; **eighteen** the model locates but has no protocol for (most of them floor-4 relational work and the eating disorders); **thirteen** behind gate 2 or in the substrate, where the model's tools are contraindicated or irrelevant and it says so; **four** programs that are not psychotherapy in the model's sense; **two** where the model makes a claim that differs from the list — debriefing (predicts the failure the evidence found) and applied relaxation (predicts conditional efficacy). The compression is real and the exclusions are principled. The two tests are the reason to trust the first sentence.

## What the author has to decide

1. Every row marked (?).
2. Whether eating disorders get a protocol or a standing referral — the drawer currently has neither, and a medical gate with nothing behind it is a gap, not a decision.
3. Whether BPD is a protocol, a module, or a referral. The rank-reactive note is adjacent, not the same.
4. Whether floor-4 relational work (IPT, CBASP, psychodynamic) gets a protocol — the model's own thesis says the floor-4 deep copy updates only through the relationship itself, which argues for a *therapist-side* protocol rather than a client-side one.
